# tfbls

TF-BLS is the data-analysis and model-fitting Python library developed for the time–frequency Brillouin light scattering method described in “Time–Frequency Brillouin Light Scattering for Mode-Resolved Phonon Dynamics.”



\---------------------------------------------------------------





The dependencies are:

&#x09;- numpy

&#x09;- matplotlib

&#x09;- scipy

&#x09;- fractions

&#x09;- numba (optional, but significantly improves the speed of .pt3 readout)
